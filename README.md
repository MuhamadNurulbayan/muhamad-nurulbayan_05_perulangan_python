## Daftar Program

### 1. Tabel Perkalian

Program untuk menampilkan tabel perkalian dari suatu bilangan yang diinput pengguna.

### 2. Jumlah Bilangan

Program untuk menghitung jumlah bilangan dari 1 sampai n menggunakan perulangan.

### 3. Validasi Input

Program untuk memvalidasi nilai agar berada pada rentang 0 sampai 100.

### 4. Hitung Bilangan Genap

Program untuk menghitung banyaknya bilangan genap dari 1 sampai n.

### 5. Deret Aritmetika

Program untuk menampilkan suku-suku deret aritmetika dan menghitung jumlah seluruh suku.

## Hasil Pengujian

### Tabel Perkalian

Input:

```text
4
```

Output:

```text
4 x 1 = 4
4 x 2 = 8
4 x 3 = 12
4 x 4 = 16
4 x 5 = 20
4 x 6 = 24
4 x 7 = 28
4 x 8 = 32
4 x 9 = 36
4 x 10 = 40
```

### Jumlah Bilangan

Input:

```text
5
```

Output:

```text
Jumlah = 15
```

### Validasi Input

Input:

```text
120
-5
75
```

Output:

```text
Nilai tidak valid.
Nilai tidak valid.
Nilai diterima: 75
```

### Hitung Bilangan Genap

Input:

```text
10
```

Output:

```text
Banyak bilangan genap = 5
```

### Deret Aritmetika

Input:

```text
a = 2
d = 3
n = 5
```

Output:

```text
Suku ke-1 : 2.00
Suku ke-2 : 5.00
Suku ke-3 : 8.00
Suku ke-4 : 11.00
Suku ke-5 : 14.00

Jumlah = 40.00
```
